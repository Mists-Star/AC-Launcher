# AC 风格门禁（Style Gates）

> 来源：移植自两个外部 skill —— `humanizer`（文案去AI味，24 类模式，基于
> Wikipedia "Signs of AI writing"）与 `hallmark`（设计反 slop 58 门禁）。
> 2026-10-16 首版。两者均为 Web/HTML 语境，本清单已裁剪到 Qt/PySide6 适用项。
> 用法：改文案、改页面样式、或发版前，照单过一遍；每条应答 **否**。

## 一、文案（i18n.py，zh + en 都要看）

- [ ] **AI 高频词**：赋能 / 极致 / 一站式 / 全方位 / 焕新 / 打造 / 沉浸式 /
      立即体验 / 开启你的；英文 additionally / crucial / delve / enhance /
      foster / showcase / seamless / vibrant / pivotal / tapestry / leverage。
      说人话：具体功能 + 具体后果，别用形容词堆。
- [ ] **升华式收尾**："未来可期 / 精彩即将呈现 / 值得期待" → 直接说下一步动作。
- [ ] **空泛引用**："业界普遍认为 / 有用户反馈" → 给出处，或删掉。
- [ ] **排比凑三**：顿号/列表硬凑三个名词 → 保留真实数量即可。
- [ ] **"不仅是A，更是B"句式**（negative parallelism）→ 一句话说清。
- [ ] **-ing 式伪深度**（英文）："highlighting…, ensuring…" 后缀短语 → 删。
- [ ] **感叹号**：只允许出现在**功能性 toast**（导入完成/联机就绪），
      标题、描述、空状态、教程正文一律无 `!`。
- [ ] **em dash（——/ —）**：叙事句 ≤1 次/句；纯占位文案（"选择实例 —"）
      属 UI 惯例可保留。
- [ ] **中英同步**：改了中文没改英文（或反之）按 bug 处理——两份字典同键
      必须同语气（案例：`ld_fabric` 的 "vibrant"）。
- [ ] **风格一致**：允许有性格（AC 口吻可以带点自嘲，如"排班中"），但同一
      页面内不能一半官腔一半皮——voice 是整体的。

## 二、视觉（theme.py / 页面 QSS / 内联样式）

- [ ] **对比度**：正文（<18px 常规字重）≥ 4.5:1；大字/图标/焦点环 ≥ 3:1。
      已知边界：暗色 `text_accent` 对 panel 仅 3.38:1 —— **只许用于 ≥18px
      粗体或大标题**，小字号禁用。自定义主题色接入时跑一遍配对计算。
- [ ] **accent 足迹 ≤ 5% 视口面积**（已用 `_audit_visual` 类饱和度审计量化，
      全页 ≤2% 线）。accent 只配：主按钮、选中态、focus 描边、进度条、
      ≤16px 小图标、3px 竖条点缀。
- [ ] **无渐变文字**（gradient text / background-clip:text）；纯按钮底
      允许唯一一处轻渐变吗？不允许——一律纯色。
- [ ] **无高饱和大色块**：类型徽章/状态标一律中性 token 或语义 token
      （success/warn/danger），不用品牌色同屏混排。
- [ ] **色值来源**：任何 `#RRGGBB` 内联须过 token；alpha 一律
      `with_alpha(hex, 0xXX)`（**alpha 在前**，`f"{accent}22"` 是事故）。
      硬编码色仅两处豁免：frameless 关闭键 hover 红、splash 径向光晕。
- [ ] **圆角卡片不套圆角卡片**（card in card）；层级用间距和字重区分。
- [ ] **交互元素四态齐**：default / hover / focus-visible（瞬现，不做淡入）
      / active；disabled 同时给透明度 + not-allowed 光标 + disabled 属性。
- [ ] **焦点/悬停不改边框宽度**（会引发布局抖动）→ 只换色、outline、阴影。
- [ ] **动效克制**：转场 ≤200ms；一个元素同一时刻只有一种 hover 反馈；
      不做弹跳/过冲缓动；装饰性动画受 `EFFECTS_ENABLED` 总开关门控
      （功能切换永不被装饰开关短路）。
- [ ] **字体 ≤3 家**（项目现状：正文 1 家 + 数字/像素点缀，达标）；
      标题不用斜体，强调靠字重/accent。
- [ ] **间距走 4px 倍数标尺**；任意 `17px` padding 是 slop tell。

## 三、发版前快速抽查

1. 中英各抽 30 条读一遍，过第一节全部项。
2. 跑饱和度/对比度脚本（本轮的离屏审计做法：grab 页面 → HSV 统计 +
   WCAG 配对），亮暗两种模式各一遍。
3. 真机目检：首页 hero、外观页、设置页——离屏无字体，文字排版只能真机看。
