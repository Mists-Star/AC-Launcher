# AC Launcher 整体对比 + 玩家视角审查报告（round-41，2026-08-13）

> 对比对象：PCL2 / HMCL / BlockHelm / Prism / MultiMC / GDLauncher / ATLauncher / CurseForge App
> 方法：功能矩阵对照 + 社区反馈（Reddit/GitHub/评测）+ 玩家视角走查

## 二、玩家视角：用着不舒服 / 不好看 / 反人类

### 交互
1. **实例页无右键菜单**——复制/备份/打开文件夹/删除全要进详情面板点按钮，鼠标流玩家不习惯（Prism 全在右键）
2. **无拖拽导入**——拖个 .mrpack 进窗口是 MultiMC 玩家本能，我们没有
3. **实例无分组**——超过 8 个实例后列表混乱，没有按"整合包/原版/光影"分组的入口
4. **无全局快捷键**——键盘流玩家（F5 刷新、Ctrl+N 新建）缺失
5. **设置项无搜索**——几十个设置项靠滚动找

### 视觉
6. 实例页偏列表朴素（小图标+文字），无封面/分组视觉层次（GDLauncher 卡片、Prism 封面更抓眼）
7. 首页 hero 只有"实例选择下拉"，玩家想改当前实例的配置要跳到实例页

### 反人类/易错
8. 实例目录被玩家删除后点启动 → 之前裸 FileNotFoundError（**已修 round-41：友好中文提示**）
9. 手填 Java 路径失效 → 之前静默 fallback 或裸错误（**已修 round-41：明确提示去设置里重选**）
10. 整合包导入失败会留空实例（**已修 round-40**）
11. 首次使用默认内存 4096MB——部分玩家内存小的会启动失败（默认值可再评估）

## 三、玩家乱搞会崩的场景（已加固项 + 建议）

| 乱搞行为 | 后果 | 状态 |
|---|---|---|
| 改坏 launcher_config.json / instances.json / accounts.json | 启动崩溃 | ✅ round-34/40 加固（容错跳过） |
| 配置文件是合法 JSON 但不是 dict | TypeError | ✅ round-34 |
| 删/移动实例目录后点启动 | FileNotFoundError | ✅ round-41 友好提示 |
| 删 Java 目录 / 手填错路径 | 启动失败 | ✅ round-41 明确提示 |
| 内存设 0/负数 | Xms>Xmx 启动失败 | ✅ round-39 兜底 2048 |
| 导入恶意整合包（zip-slip） | 任意文件写入 | ✅ round-35/40 safe_extract |
| 下载中断/断网 | 整文件重下 | ✅ round-38 断点续传 |
| 下载中关窗 | heap corruption 0xC0000374 | ✅ round-34/40 drain+中断 |
| 同时开两个启动器 | 双实例冲突 | ✅ 单实例锁 |
| 快速双击/狂点启动 | 重复进程 | ✅ 按钮禁用 + 单实例锁 |
| 壁纸放超大视频 | 内存膨胀 | 🗂 建议限制大小/分辨率 |
| 磁盘满时下载 | NetError 显示 | 🗂 建议友好提示磁盘空间 |

## 四、行动建议（下一轮起按序）

1. **Mod 一键更新**（最高频需求）：资源中心加"已安装 mod 检测 + 更新"——扫描实例 mods 目录的 Modrinth project_id（fabric.mod.json 有 id），对比在线最新版本号，一键批量更新
2. **实例分组 + 复制**：实例页加分组头 + 复制入口（Prism Ctrl+D 等价）
3. **实例级设置覆盖**：详情面板加 Java/内存/参数覆盖
4. **右键菜单**：实例行/实例卡加 QMenu（打开文件夹/复制/备份/导出/删除/设为当前）
5. 存档管理、自动下载源、备份——按使用反馈推进
